# AI Application Overview

<img src="media/page_ai_application_overview.png" alt="Image - AI Application Overview" style="display: block; margin: 0 auto">

The **AI Application Overview** has been designed to provide you with all the information that you might need to undertake an audit.  

The audit instigator will have provided the details listed and should be contacted if you feel further information would be helpful. However, it is worth noting that in some cases additional information may not be accessible. Some datasets may contain sensitive information and cannot be legally shared, in other cases the AI technology within the application may be ‘opaque-box’ and therefore while users can see the system’s inputs and outputs, they can’t see what happens to produce those outputs. 

Click on the ⌄ (down arrow) to the right of each section to view the information contained within.  

- **AI Application Summary:** This will provide a general overview of the AI application and its purpose.
- **Audit Details:** Who has initiated and set up this audit and for which purpose. 

- **Audit Application Environment:** Where and how the AI application is used. 

- **AI Application Development Pipeline:** Why and how the AI Application is built and run. 

    - **Business Case:** What the motivation for and goal of the AI Application is. 
    
    - **Dataset:** Characteristics of the data used to create/train and then test the AI Application. 
    
    - **AI Model Architecture:** How the AI Applications makes decisions. 
    
    - **Testing and Evaluation:** How the Application has been previously assessed. 
    
    - **Deployment:** How and where is the AI Application being released.

- **Legal Framework:** Which legal obligations does the AI Application have to fulfil. 

Once you have read all the information provided, it is time to move on to the next step, **Audit Criteria. **
