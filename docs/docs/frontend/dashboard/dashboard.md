# Dashboard

<img src="media/page_dashboard.png" alt="Image - Dashboard" width="1000" style="display: block; margin: 0 auto">

The dashboard contains a list of all the audits you have been invited to participate in. For many people, this will only be one audit. 

Here you can view the name of each **Audit **with the **Audit Instigator** listed below, as well as the name of the **AI Application** you will be auditing. The **Status** of the audit (‘not started’, ‘in progress’ or ‘finished’) is also provided with an accompanying **Audit Status** which is a progress bar allowing you to see how far through the audit you currently are.  

Please start by clicking **Enter Audit** for the audit you wish to participate in; you will then be taken to the **AI Application Overview. **
