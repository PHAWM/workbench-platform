You will be asked to provide the following information for a qualitative metric: 

- **Metric Name:** Decide on a name that represents a way to measure the event if it is happening 

- **Metric Description: **Describe how to measure an event if it is happening 

- **Why you are adding this metric?:** Describe your reasoning for adding this metric 

- **Scale Points: ** Decide how many measurement points you want for this metric (max 20) 

- **Scale Labels: **Decide how to label each point on your scale and choose which value on the scale is still acceptable for this metric by checking the box next to it 

- **Features (Optional): **Choose or create what aspect of the AI Application output you want to compare 

Once you have filled in the boxes, **Save Qualitative Metric** to return to the **Audit Criteria.** It will now be possible to add this metric to any event.
