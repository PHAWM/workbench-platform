You will be asked to provide the following information for a quantitative metric: 

- **Metric Name: **Decide on a name that represents a way to measure the event if it is happening 

- **Metric Description: **Describe how to measure an event if it is happening 

- **Why are you adding this metric?:** Describe your reasoning for adding this metric 

- **Target: **Choose or create what aspect of the AI Application output you want to compare 

- **What is the threshold you wish to assign to this metric?: **Decide the value of the metric performance that is still acceptable to you. 

- **Define Distinguishing Factor Groups: **Decide the values, or range, of each group you want to compare 

- **Distinguishing Factor:** Choose or create the factor you want to compare this metric on  
  - **Number of Groups for Comparison:** Decide how many groups you want to compare within the Distinguishing Factor 
  - **Define Distinguishing Factor Groups:** Decide the values, or range, of each group you want to compare
 

Once you have filled in the boxes **Save Quantitative Metric** to return to the **Audit Criteria**. It will now be possible to add this metric to any event. 

Once you have looked at the existing events and metrics and added any additional metrics to the events, you can start consider adding additional events with **+ Create New Events**.
