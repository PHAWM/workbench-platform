# Audit Criteria

<img src="media/page_audit_criteria.png" alt="Image - Audit Criteria" width="1000" style="display: block; margin: 0 auto">

The is where the process of auditing the AI application begins, you should start reviewing the **Audit Criteria **that have been provided. Each **Audit Criteria** consists of two parts, the **Event** that may occur if the AI application is used and the **Metric** that could be used to measure if an event is happening and how  

An **Event** can be positive or negative things that you think could happen when the AI application being used. For example, if a bank were to use an AI application to decide who was eligible for a loan, one Event might be “Decreased loan decision time” another might be “Gender affects loan decision outcome”. 

The boxes on the left of the screen contain the event name, a brief description of that event, and the option to **Edit Event Values.** If you click on the arrow in the top right corner of the box, more details about the event will be provided. Once you have read through the details, you should begin by select **Edit Event Values**.
