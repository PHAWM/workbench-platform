Start by uploading any data you have with the **Upload** button. Once all the relevant files have been uploaded, you can Start Evaluation. 

<img src="/media/page_output_evaluation_tab_two.png" alt="Image - Output Evaluation Results" width="600" style="display: block; margin: 0 auto">

The workbench will analyse the data and provide you with an** Output Evaluation**. At this point you have the option to decide if the output has met metric expectations or not and if so, give feedback and a justification for your decision.  

Next, you should click **Save Output Evaluation** and return to the** Performance Analysis.** Here you can review the Performance Analysis and **Output Evaluation** side by side before giving your metric **Recommendation** and **Feedback and Justification**.  

Once you have completed the analysis for EACH criteria, you can move onto the final stage of the audit **Next to Audit Recommendation **.
