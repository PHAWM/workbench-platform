The Audit Recommendation is a summary of all the Criteria you have that that you have reviewed and the recommendations you have made. For each **Criteria** you are given the name of the associated **Event** and the **Metric**, the recommendation you made (pass/fail/inconclusive), as well as the feedback and justification notes.  

At this stage you should decide whether you think the AI application has passed or failed the audit, though if you do not feel you have enough evidence to decide, you can determine the outcome to be inconclusive.  

As well as providing your **Overall Recommendation**, you should provide additional **Feedback and Justification**. Once this has been completed, please review the details of your audit carefully and Submit Audit Recommendation, at this point you will be returned to the **Dashboard** and will no longer be able to edit the audit.  

Thank you for participating in this audit!  If you have any feedback about this auditing process, this User Manual or the PHAWM Workbench, please send it to: **phawm_project@glasgow.ac.uk**
